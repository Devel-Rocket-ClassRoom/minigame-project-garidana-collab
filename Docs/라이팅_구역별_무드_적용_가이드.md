# 구역별 라이팅 무드 적용 가이드

**작성일:** 2026-06-06
**대상:** Unity 6.3 / URP 17.3 / PC 우선 / 구역별 고정 무드

새로 추가된 스크립트 (`Assets/Scripts/Lighting/`):

| 파일 | 역할 |
| --- | --- |
| `LightingZoneProfile.cs` | 구역별 무드 프리셋 (ScriptableObject) |
| `LightingZoneController.cs` | 디렉셔널/앰비언트/포그 블렌딩 싱글톤 (씬에 1개) |
| `LightingZoneTrigger.cs` | 구역 진입 트리거 (BgmZoneTrigger와 동일 패턴) |

---

## 1. 구역별 프로필 권장 값

`Assets > Create > KA Origin > Lighting Zone Profile`로 5개 생성 후 아래 값 입력.

| 항목 | 천호마을 | 황무지 | 어둠숲 | 오크 주둔지 | 왕의 무덤 |
| --- | --- | --- | --- | --- | --- |
| Directional Color | `#FFD9A8` | `#FFF4D6` | `#7E96A3` | `#B8B2A6` | `#4A5566` |
| Directional Intensity | 1.2 | 1.5 | 0.5 | 0.7 | 0.15 |
| Ambient Color | `#9C8B73` | `#8A7E66` | `#2E4040` | `#4A4742` | `#141C2B` |
| Fog Enabled | ✅ | ✅ | ✅ | ✅ | ✅ |
| Fog Color | `#E8D4B0` | `#D9C292` | `#1F3833` | `#5C554C` | `#0D1420` |
| Fog Density | 0.004 | 0.008 | 0.035 | 0.015 | 0.05 |

값은 시작점이며, 씬에서 보면서 조정. 특히 Fog Density는 맵 스케일에 따라 체감이 크게 다름.

## 2. 씬 셋업 절차

1. **컨트롤러 배치**: 빈 GameObject `LightingZoneController` 생성 → 스크립트 부착 → `Directional Light` 연결, `Default Profile`에 천호마을 프로필 연결.
2. **트리거 배치**: 구역마다 BgmZoneTrigger 쓰던 것과 같은 위치/크기로 트리거 콜라이더 + `LightingZoneTrigger` 부착 → 프로필 연결. (기존 BGM 트리거 오브젝트에 같이 붙여도 됨)
   - 구역이 겹치는 경계부는 `priority`로 해결 (좁은 구역을 높게).
   - `fadeDuration` 2~3초 권장.
3. **구역별 포스트 Volume(선택)**: 구역마다 빈 GameObject에 `Volume` 컴포넌트(**Global 모드, Weight 0**) + Volume Profile 생성 → 트리거의 `Zone Volume`에 연결. 진입 시 weight가 자동으로 교차 페이드됨.
   - 추천 오버라이드: Color Adjustments(채도/색온도), Vignette, Bloom.
   - 무덤/어둠숲: Vignette 0.35~0.45, 채도 -20, 천호마을: 색온도 +10, Bloom 약하게.

## 2-1. 구역별 Volume 오버라이드 권장 값

각 구역 Volume Profile에 아래 오버라이드 추가 (없는 항목은 추가 안 함).

| 오버라이드 | 천호마을 | 황무지 | 어둠숲 | 오크 주둔지 | 왕의 무덤 |
| --- | --- | --- | --- | --- | --- |
| **Color Adjustments** | | | | | |
| └ Post Exposure | 0 | +0.2 | 0 | 0 | -0.3 |
| └ Contrast | +5 | +15 | +10 | +10 | +20 |
| └ Saturation | +5 | -10 | -25 | -20 | -30 |
| └ Color Filter | – | – | `#A8C8C0` | – | `#B8C4E0` |
| **White Balance** | | | | | |
| └ Temperature | +10 | +15 | -15 | -5 | -20 |
| └ Tint | 0 | +5 | 0 | 0 | 0 |
| **Vignette** | | | | | |
| └ Intensity | 0.15 | 0.2 | 0.4 | 0.3 | 0.45 |
| └ Smoothness | 0.4 | 0.4 | 0.5 | 0.5 | 0.6 |
| **Bloom** | | | | | |
| └ Intensity | 0.3 | 0.2 | 0.4 | 0.5 | 0.6 |
| └ Threshold | 1.1 | 1.2 | 0.9 | 0.9 | 0.8 |
| **Film Grain** | – | – | Thin 1, 0.15 | Thin 1, 0.25 | Thin 1, 0.2 |

의도: 마을→무덤으로 갈수록 채도↓·콘트라스트↑·비네트↑로 긴장 고조. 어둠숲/무덤의 낮은 Bloom Threshold는 포인트 라이트(신비광/횃불)가 어둠 속에서 빛나 보이게 하기 위함. Color Filter는 화면 전체에 옅은 색조를 얹는 것이라 과하면 탁해짐 — 채도 낮은 밝은 색 유지.

## 3. 라이트맵 베이크 절차 (분위기 확정 후)

1. 지형/건물/바위 등 안 움직이는 오브젝트 전부 선택 → Inspector 우상단 **Static** 체크 (Contribute GI 포함).
2. `Window > Rendering > Lighting`:
   - Lightmapper: **Progressive GPU**
   - Lightmap Resolution: 10~20 texels (테스트는 5로 빠르게)
   - Directional Light Mode를 **Mixed**로 → 정적은 베이크, 플레이어/몬스터는 실시간 그림자 유지.
3. **Light Probe Group**을 각 구역 플레이 동선에 배치 (움직이는 캐릭터가 구역 빛을 받게 함).
4. `Generate Lighting` 실행.

⚠️ 주의: 디렉셔널 색/세기를 런타임에 블렌딩하는 구조이므로, **베이크 기준은 중간톤(천호마을 프로필)으로 굽고**, 구역별 차이는 실시간 디렉셔널 + 앰비언트 + 포그 + Volume이 담당. 구역별로 베이크 결과 자체를 다르게 하고 싶으면 구역별 씬 분리가 필요한데, 3주 일정에는 비추천.

## 4. 실시간 라이트 (PC 예산)

- 횃불/모닥불: Point Light, 색 `#FF9C40`, Range 6~10, 간단한 깜빡임은 intensity에 `Mathf.PerlinNoise` 흔들기.
- 오크 주둔지 모닥불 3~5개, 왕의 무덤 횃불 6~10개 수준이면 PC에서 문제없음.
- 실시간 그림자는 디렉셔널 1개만. 포인트 라이트는 그림자 끄기.

## 5. 테스트 체크리스트

- [ ] 구역 이동 시 2~3초에 걸쳐 자연스럽게 톤 전환되는가
- [ ] 구역 경계 왕복 시 깜빡임/되돌림 없는가 (priority 확인)
- [ ] 플레이어/몬스터가 어두운 구역에서 혼자 밝지 않은가 (프로브 확인)
- [ ] 게임 시작 직후 기본 프로필이 적용되는가
