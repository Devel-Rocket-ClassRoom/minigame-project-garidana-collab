## 1. 구현 완료된 시스템

`Assets/Scripts/Lighting/` 신규 스크립트 4개:

| 스크립트 | 역할 | 상태 |
| --- | --- | --- |
| `LightingZoneProfile.cs` | 구역별 무드 프리셋 SO (디렉셔널/앰비언트/포그) | ✅ 동작 확인 |
| `LightingZoneController.cs` | 싱글톤. 프로필 블렌딩 + Volume weight 교차 페이드. Awake에서 Ambient Flat / Fog ExpSquared 강제 | ✅ 동작 확인 |
| `LightingZoneTrigger.cs` | 구역 진입 트리거 (BgmZoneTrigger와 동일한 우선순위 패턴) | ✅ 동작 확인 |
| `MiniMapLightingOverride.cs` | 미니맵 카메라 렌더 순간만 라이팅 고정값 덮어쓰기 (구역 무드가 미니맵 오염시키는 문제 해결) | ✅ 적용됨 |

## 2. 현재 씬(SampleScene) 구성 (분석 기준 2026-06-06)

### 프로필 에셋 — `Assets/Lighting/` 5개 생성·연결 완료

| 프로필 | Directional | Intensity | Ambient | Fog Density |
| --- | --- | --- | --- | --- |
| Chunho_Town | `#FFF2DC` (밝은 백색) | 1.3 | `#BFC8CE` (밝은 하늘빛) | 0.002 |
| Desert | `#FFF4D6` | 1.5 | `#8A7E66` | 0.008 |
| Forest | `#7E96A3` | 0.5 | `#2E4040` | 0.035 |
| OrcBase | `#B8B2A6` | 0.7 | `#4A4742` | 0.015 |
| KingsTomb | `#4A5566` | 0.15 | `#141C2B` | 0.05 |

※ 천호마을은 초안의 탁한 갈색 톤에서 "화사하고 밝은" 방향으로 수정 완료된 상태.

### 씬 오브젝트

- **LightZoneController** 1개 — Directional Light 연결, Default Profile = Chunho_Town ✅
- **LightingZoneTrigger** 5개 — 5구역 프로필 전부 연결, fadeDuration **0.5초**, priority 전부 0
- **구역 Volume** 4개 (Global 모드, weight 0 시작): Volume_Town / Desert / Forest / Tomb
  - Volume Profile 에셋은 `Assets/Scenes/SampleScene/` 폴더에 자동 생성됨
- **MiniMapLightingOverride** — MiniMapCamera에 부착, 고정 백색광(1.2)/앰비언트(0.75 회색) ✅
- 기존 Global Volume (weight 1, SampleSceneProfile)은 그대로 유지

### 동작 확인된 것

- 구역 진입 시 프로필 전환 + 페이드 정상 동작
- 미니맵 라이팅 오염 문제 해결

## 3. 발견된 이슈 / 주의사항

1. **오크 주둔지 전용 Volume 없음** — OrcBase 트리거의 Zone Volume이 **Forest 트리거와 같은 Volume을 공유** 중. 의도가 아니면 `Volume_OrcBase`를 따로 만들어 연결할 것 (가이드 2-1절 값 참고).
2. fadeDuration이 전 구역 0.5초로 설정됨 — 빠른 전환 선호로 보이나, 톤 차이가 큰 구역(황무지→어둠숲)은 1~1.5초가 더 자연스러울 수 있음.
3. Volume Profile 에셋이 `Assets/Scenes/SampleScene/`에 흩어져 있음 — `Assets/Settings/` 등으로 정리 권장 (선택).
