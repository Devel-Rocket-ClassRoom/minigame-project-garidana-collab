# <김경일의 모험 : Origin> 발표 요소

## 게임 개요
- 오픈월드 모방형 쿼터뷰 액션 RPG
- 퀘스트를 진행하면서 게임의 세계관을 경험하고 다양한 맵과 몬스터들을 접하는 게임.

## 게임 흐름
- 맵의 다양한 지형 (구역)을 오가며 퀘스트 -> 전투 -> 성장 -> 보스 처치 (엔딩)
- 천호마을에 닥친 위기의 숨겨진 원인을 밝히는 내용

## 게임 설명
- 순서대로 진행되는 퀘스트 (선행 퀘스트 후 다음 퀘스트 진행 가능)
- 맵
    - 천호마을
    - 마력의 황무지
    - 어둠 숲
    - 오크 주둔지
    - 왕의 무덤
- 퀘스트 
    - 구역에 존재하는 NPC에게 퀘스트를 받아 스토리를 진행.
- 마을
    - 장비 상인
    - 회복 술사

## 구현 내용
- 플레이어
- 공격 이펙트
- 몬스터 / 보스 몬스터
- 퀘스트 시스템
- 장비/인벤토리 (툴팁)
- 웨이포인트
- 세이브 로드
- 플레이어 공격강화
- 구역별 사운드트랙/라이팅 전환


## 핵심 구현 내용 
- 구역별 사운드트랙/라이팅 전환
- 플레이어 공격 강화
- 세이브로드 (최적화) / 웨이포인트 시스템
    - 웨이포인트 활성화 후 사용

- 장비 인벤토리 툴팁
    - 마우스 포인터를 따라오는 장비의 스탯을 보여주는 툴팁
- 퀘스트 시스템
    - Sciptabel Object 기반
    - 선형적 퀘스트 진행 (LinkedList처럼 노드 관리)
    - 상태로 관리
        - Locked
        - InProgress
        - ReadyToComplete
        - Completed (다음 퀘스트로 진행 가능)
- 퀘스트 연동 가이드 미니맵
    - 퀘스트의 상태를 보고 화살표로 다음 퀘스트 NPC의 위치 표시

## 느낀점
- 연출이 상당히 중요함 특히 RPG장르의 경우
- 당연하다고 생각되었던 요소들이 실제 개발 단계에서는 놓치기 쉬움
    - 디테일 적인 부분
        - 타격감
        - 사운드 (아이템 획득, 퀘스트 창 팝업, 전체적인 효과음)
- 밸런스
    - 넓은 맵을 구현 하려고 하는 욕심으로 인해 몬스터 패턴 다양화를 하지 못함 -> 몬스터가 단순해 난이도 밸런스 조절이 상당히 어려웠음
    - 플레이어 스탯, 장비 스탯 고정 후 몬스터 체력/데미지/사거리/공격속도 와 장비 가격을 변동하며 밸런스 조절
