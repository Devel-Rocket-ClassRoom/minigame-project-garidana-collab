# 김경일의 모험 : Origin 빌드 3 빌드 노트

게임 : 김경일의 모험 : Origin
담당자 : 오준환
제작자 : 나상욱

## 3주차 빌드 추가 구현 현황

1. 웨이포인트 시스템
    - 전 지역 웨이포인트 연결 완료

2. 인벤토리 시스템
    - 아이템 획득 및 장비 교체 (외형 포함)
    - 아이템 마우스 포인터 토글 

3. 상점 시스템
    - 상점에서 아이템 구매
    - 구매 후 아이템 제거 (상점 리스트에서)
    - 구매 후 골드 차감

4. 상자 시스템
    - 무기 / 방패는 상자에서 드랍
    - 아이템 드랍후 플레이어에게 자동으로 습득 애니메이션 구현

5. 퀘스트 NPC UI 개선
    - 퀘스트 진행 창 구현
    - 퀘스트 완료 창 구현
    - 진행가능 퀘스트 및 완료 가능 퀘스트 인디케이터

6. 몬스터 피격 이펙트
    - 플레이어 공격 강화단계별로 다른 몬스터 피격 이펙트

7. 세이브 로드 구현
    - 웨이포인트 상호작용 시 저장
    - 메인 타이틀 화면에서 세이브 삭제 기능
    - 레벨
        - 공격 강화 단계
    - 경험치
    - 퀘스트 진행상황
    - 장비 착용 현황
    - 인벤토리 현황
    - 상점 아이템 재고 현황
    - 활성화 웨이포인트 현황
    - 암호화 X

8. 게임 시작 시 키조작 튜토리얼
    - 첫번째 퀘스트 완료시 비활성화

9. 사운드 삽입
    - 메인 타이틀 음악
    - 맵 구역별 배경음악 삽입
