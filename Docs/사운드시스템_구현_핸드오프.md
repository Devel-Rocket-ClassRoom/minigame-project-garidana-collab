## 2. 현재 구현된 사운드 시스템 구조

### SoundManager.cs
`Assets/Scripts/Sound/SoundManager.cs`

- `RuntimeInitializeOnLoadMethod(BeforeSceneLoad)`로 게임 시작 시 자동 생성
- `DontDestroyOnLoad`로 씬 전환에도 유지
- **씬에 직접 오브젝트를 배치할 필요 없음**
- Hierarchy의 DontDestroyOnLoad 섹션에 `[SoundManager]` 오브젝트가 자동 생성됨
- `Assets/Resources/Audio/AudioMixer` 경로에서 AudioMixer를 `Resources.Load`로 로드
- `Assets/Resources/Audio/SoundData` 경로에서 SoundData를 `Resources.Load`로 로드

초기화 순서 주의점:
- `AddComponent` 시 `Awake`가 즉시 실행되므로 static 필드(`_pendingMixer`, `_pendingData`)에 먼저 저장 후 `Awake`에서 읽어오는 방식 사용
- `Start`가 아닌 `Awake`에서 `SetupAudioSources()`와 `LoadVolumes()` 호출

AudioMixer 그룹 연결:
- `FindMatchingGroups("BGM")`으로 BGM AudioSource에 BGM 그룹 연결
- `FindMatchingGroups("SFX")`으로 SFX AudioSource에 SFX 그룹 연결

볼륨 제어:
- `SetMasterVolume(float)`, `SetBGMVolume(float)`, `SetSFXVolume(float)` — 0~1 값을 dB로 변환해 AudioMixer에 적용
- `PlayerPrefs`로 볼륨 값 저장/불러오기 처리됨
- 저장 키: `Pref_MasterVolume`, `Pref_BGMVolume`, `Pref_SFXVolume`

### SoundData.cs
`Assets/Scripts/Sound/SoundData.cs`

모든 AudioClip 레퍼런스를 담는 ScriptableObject.
`Assets/Resources/Audio/SoundData.asset`에 인스턴스가 있어야 함.

슬롯 목록:
- BGM: `bgmMainTitle`, `bgmGameplay`, `bgmBoss`
- UI: `buttonClick`, `chestOpen`, `waypointActivate`, `goldSpend`, `noGold`
- Player: `playerAttackVoice`, `swordSwing`, `playerHit`, `playerDeath`, `dash`, `levelUp`, `footstep`
- Monster: `monsterHit`, `monsterDeath`

### UiSoundHandler.cs
`Assets/Scripts/Sound/UiSoundHandler.cs`

- `RuntimeInitializeOnLoadMethod`으로 자동 생성
- `SceneManager.sceneLoaded` 이벤트를 구독해 씬 로드 시마다 씬 안의 모든 `Button`을 스캔
- 모든 버튼에 `ButtonClick` SFX 리스너 자동 등록 (중복 방지 처리됨)
- 개별 버튼 스크립트에 따로 코드 추가 불필요

## 3. AudioMixer 설정 (Unity 에디터)

**Mixer 파일 위치:** `Assets/Resources/Audio/AudioMixer.mixer`

그룹 구조:
```
Master
├── BGM
└── SFX
```

Exposed Parameters (코드와 이름이 정확히 일치해야 함):
- `MasterVolume` — Master 그룹
- `BGMVolume` — BGM 그룹
- `SFXVolume` — SFX 그룹

설정 방법: AudioMixer 창에서 각 그룹 선택 → Inspector의 Volume 옆 톱니바퀴 클릭 → "Expose to script" → Exposed Parameters 탭에서 이름 변경

## 4. 각 스크립트에 추가된 PlaySFX 호출 위치

| 스크립트 | 위치 | SFX 타입 |
|---|---|---|
| `PlayerAttack.cs` | `StartComboAttack()` 내부 | `SwordSwing`, `PlayerAttackVoice` |
| `PlayerStats.cs` | `TakeHit()` - 피격 시 | `PlayerHit` |
| `PlayerStats.cs` | `LevelUp()` 내부 | `LevelUp` |
| `PlayerStats.cs` | `Die()` 내부 | `PlayerDeath` |
| `PlayerMovement.cs` | `StartDash()` 내부 | `Dash` |
| `BaseMonster.cs` | `TakeHit()` - 피격 시 | `MonsterHit` |
| `BaseMonster.cs` | `Die()` 내부 | `MonsterDeath` |
| `ChestInteractable.cs` | `OpenLid()` 내부 | `ChestOpen` |
| `WaypointManager.cs` | `UnlockWaypoint()` - 첫 해금 시 | `WaypointActivate` |

호출 방식은 항상 null 조건 연산자를 사용:
```csharp
SoundManager.Instance?.PlaySFX(SoundManager.SFXType.SwordSwing);
```

## 5. OptionMenuUi 볼륨 슬라이더 연결

`Assets/Scripts/UI/OptionMenuUi.cs`에 슬라이더 필드 3개 추가됨:
```csharp
[SerializeField] private Slider masterVolumeSlider;
[SerializeField] private Slider bgmVolumeSlider;
[SerializeField] private Slider sfxVolumeSlider;
```

`InitVolumeSliders()`에서 SoundManager에서 저장된 볼륨값으로 슬라이더 초기화 후 `onValueChanged` 리스너 연결.

Unity 에디터에서 해줄 작업:
- 옵션 패널 UI에 Slider 3개 추가
- Inspector에서 `masterVolumeSlider`, `bgmVolumeSlider`, `sfxVolumeSlider` 슬롯에 연결

## 6. 현재 사운드 리스트에서 미구현 항목

`Docs/사운드 리스트/사운드리스트.md` 기준으로 아직 PlaySFX 호출이 없는 항목:

- **발걸음 소리**: SoundData에 `footstep` 슬롯은 있으나 호출 코드 미작성. `PlayerMovement.cs`에서 이동 중 주기적으로 호출하는 로직 필요
- **BGM 재생**: `SoundManager.PlayBGM(SoundManager.BGMType.Gameplay)` 호출하는 코드가 아직 없음. 씬별로 적절한 위치(씬 로드 시, 보스방 진입 시 등)에 추가 필요

## 7. 현재 Resources 폴더 구조

```
Assets/Resources/Audio/
├── AudioMixer.mixer       ← 기존 Assets/Audio/Mixers/ 에서 이동됨
└── SoundData.asset        ← SoundData ScriptableObject 인스턴스
```

이 폴더 구조가 없으면 게임 시작 시 다음 경고가 콘솔에 출력됨:
- `[SoundManager] AudioMixer를 찾을 수 없습니다.`
- `[SoundManager] SoundData를 찾을 수 없습니다.`

## 8. 디버그 로그 현황

현재 코드에 디버그 로그가 남아 있음. 사운드 시스템이 안정화되면 제거 권장:

- `SoundManager.Initialize()` — mixer/data 로드 성공 여부 출력
- `SoundManager.Awake()` — mixer/data 할당 여부 출력
- `SoundManager.PlaySFX()` — 재생 시 출력, 클립 없을 시 경고 출력
- `SoundManager.SetMixerVolume()` — SetFloat 실패 시 경고 출력
